# Investment Simulator

An interactive investment strategy simulator that is built with **Panel** and **Python**.
The application enables its users to backtest different investment strategies such as
Dollar-Cost Averaging (DCA), Lump Sum, and SMA-based strategies on single stocks
or equal-weight portfolios.

## Features
- Interactive web-based UI (Panel)
- Single-stock and multi-stock portfolio simulation
- Equal-weight portfolio investing
- Strategy comparison
- Key performance metrics (return, volatility, drawdown)
- Industry sector-based portfolio selection
